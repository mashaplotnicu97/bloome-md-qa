# TC-03 — Mobile Responsive Layout Verification

## Module
Responsive Design

## Priority
Medium

## Preconditions
Website is opened in browser.

## Test Steps
1. Open https://bloome.md
2. Open browser developer tools
3. Switch to mobile device view (iPhone/Samsung)
4. Navigate through the website

## Expected Result
- Content fits mobile screen correctly
- No overlapping elements visible
- Images display properly
- Buttons remain clickable
- Text is readable
