# bloome-md-qa

## Project Overview
Manual QA testing portfolio project for https://bloome.md

This project includes manual testing documentation created for website functionality, usability, and responsive behavior validation.

---

## Scope of Testing
- Functional Testing
- UI/UX Testing
- Responsive Testing
- Form Validation Testing
- Cross-browser Testing

---

## Testing Types Performed
- Smoke Testing
- Regression Testing
- Exploratory Testing

---

## Tools Used
- Jira-style bug reporting
- Postman
- Chrome DevTools
- Excel
- GitHub

---

## Browsers Tested
- Google Chrome
- Safari

---

## Devices Tested
- MacBook Pro
- iPhone 12 Pro

---

## Project Structure

### TestCases
Contains manual test cases for core website functionality.

### BugReports
Contains documented bugs with reproduction steps and expected results.

### Checklists
Contains smoke testing checklist documentation.

### Screenshots
Contains screenshots related to detected issues and responsive testing.

### API
Contains basic API testing collections and requests.

---

## Goal of the Project
The purpose of this project is to demonstrate practical manual QA skills including:
- test documentation
- bug reporting
- test design
- responsive testing
- analytical thinking
