# Test Plan — bloome.md

## Objective
The objective of this testing is to verify the functionality, usability, responsiveness, and overall user experience of the bloome.md website.

---

## Scope of Testing
The following areas are included in testing:
- Homepage functionality
- Navigation menu
- Responsive design
- Forms validation
- UI/UX behavior
- Footer links
- Cross-browser compatibility

---

## Testing Types
- Functional Testing
- Smoke Testing
- Regression Testing
- Exploratory Testing
- Responsive Testing
- UI Testing

---

## Browsers Tested
- Google Chrome
- Safari

---

## Devices Tested
- MacBook Pro
- iPhone 12 Pro

---

## Tools Used
- Chrome DevTools
- Postman
- GitHub
- Excel

---

## Test Deliverables
The project includes:
- Test Cases
- Bug Reports
- Smoke Testing Checklist
- Screenshots
- API Testing Collection

---

## Risks
Potential risks identified during testing:
- Responsive layout inconsistencies
- Broken links
- Form validation issues
- UI alignment issues on mobile devices

---

## Out of Scope
The following testing types are not included:
- Performance Testing
- Security Testing
- Automation Testing

---

## Conclusion
Testing activities were performed to identify usability and functionality issues and to improve overall website quality and user experience.
